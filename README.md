# CivicLens

CivicLens is an evidence-grounded civic intelligence platform.

It uses Retrieval-Augmented Generation (RAG) to help users understand
government documents, policies, regulations, civic procedures, and
public datasets.

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- pgvector
- Next.js
- Sentence Transformers
- BGE-M3
- RAG
- PostGIS

## Goal

Provide reliable answers backed by official government sources
with page-level citations and evidence verification.
